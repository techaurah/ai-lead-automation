# Roadmap: AI Lead Automation

Where this blueprint is going after v0.1.0. This is a plan, not a
promise: items land when they are written, checked against real
implementations, and reviewed, in roughly this order.

## What v0.2 adds

- **Worked example implementation notes:** one stage of the
  pipeline (capture to CRM write) implemented step by step on a
  named stack, with the decisions, settings, and dead ends
  written down, so the patterns are easier to follow.
- **More CRM mappings:** field mapping examples beyond the
  current four CRMs (HubSpot, Pipedrive, GoHighLevel, Google
  Sheets), starting with the CRMs readers ask for most.
- A qualification prompt variant pack for after-hours and
  weekend inquiries, the hours this blueprint exists for.
- Booking edge cases: reschedules, no-shows, and double-booking
  attempts, as patterns with stop conditions.

## Deliberately out of scope

- **Not a hosted product or SaaS.** Nothing here runs for you;
  there is no product collecting your data.
- **Not ready-made software for a specific stack.** The prompts,
  fields, and sequences are patterns to adapt, not an install.
- **It does not generate the inquiries.** The blueprint covers
  lead handling after an inquiry arrives; marketing stays
  your job.

## How priorities are set

Priorities are set from GitHub issues and Discussions: open an
issue for errors, unclear sections, and concrete additions (a
new CRM mapping starts as an issue naming the CRM), and start a
discussion for ideas and questions.
